How to use this kit.

1. Extract the ZIP and open this page. Browse the handbook and visual atlas.
2. Try the local interaction study. Refresh resets its synthetic state; connectivity is only simulated.
3. Give the whole folder to the implementing Agent. Confirm the repo and environment before editing.
4. Implement in stages and produce actual test evidence. Do not claim planned scenarios have passed.
